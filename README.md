## Overview

**Your second brain, privately indexed.** PAPERBRAIN ingests your documents, emails, and web pages into a private vector store, then answers your questions with cited passages pulled straight from your own knowledge base — no hallucinated sources. Every response is grounded in retrieval-augmented generation (RAG) over content that never leaves the server it's indexed on. The interface leans into a "Swiss, high-contrast" design language: dark mode by default, dense information layouts for document management, and clear encryption/privacy indicators throughout.

## ✨ Features

### 📚 Knowledge Base
- Upload documents, emails, or web pages — everything is chunked and embedded locally
- Supports PDF, DOCX, TXT, MD, `.eml` emails, and web URLs, all normalized automatically
- Per-document privacy & encryption status indicators
- Deleting a document removes every trace of it from the vector store instantly

### 💬 AI Chat with Citations
- Tri-pane layout: collapsible chat history rail, centered transcript, right-hand citation/sources panel
- Answers generated by **Claude Sonnet 4.5**, grounded in retrieved passages from your own documents — every claim is traceable, not hallucinated
- Token-by-token streaming responses with visible, clickable citation tags (`[1]`, `[2]`...) that open the exact source snippet

### 🔐 Authentication & Security
- Email + password signup/login (JWT, bcrypt-hashed passwords)
- Google OAuth via Emergent-managed auth session flow
- Email verification on signup
- Forgot/reset password via transactional email (Resend) — designed to avoid email enumeration
- Authenticated in-app password change
- Per-user vector namespaces — no cross-account data access, no third-party analytics or tracking

### 💳 Usage Tiers
- Freemium model with per-account limits (documents, vector chunks, chats/month) surfaced directly in the dashboard, with an in-app upgrade path to a paid plan

### 🎨 Design System
- Swiss & high-contrast visual language, dark mode default, full light-mode support
- Typography: Cabinet Grotesk (headings), IBM Plex Sans (body), IBM Plex Mono (metadata/citations/timestamps)
- Built on shadcn/ui components + Phosphor Icons
- Accessibility-conscious: minimum 4.5:1 text contrast, visible focus states, respects `prefers-reduced-motion`

## 🔌 API Reference — Auth

All authenticated routes expect an `Authorization: Bearer <jwt>` header.

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/auth/signup` | Create account (email + password) |
| `POST` | `/api/auth/login` | Log in, returns JWT |
| `POST` | `/api/auth/google/session` | Exchange Emergent Google session for a JWT |
| `POST` | `/api/auth/forgot-password` | Trigger password-reset email |
| `POST` | `/api/auth/reset-password` | Set a new password using a reset token |
| `POST` | `/api/auth/verify-email` | Confirm email using a verification token |
| `POST` | `/api/auth/change-password` | Change password (authenticated) |

## 🚀 Getting Started

### Prerequisites
- Node.js + Yarn
- Python 3.10+
- A MongoDB instance (local or Atlas)

### Environment Variables (`backend/.env`)
```env
MONGO_URL=
DB_NAME=
JWT_SECRET=
RESEND_API_KEY=            # placeholder mode logs emails to console instead of sending
ANTHROPIC_API_KEY=         # powers Claude Sonnet 4.5 chat responses
CHROMA_PERSIST_DIR=        # local path for the ChromaDB vector store
```

### Installation

```bash
# Backend
cd backend
pip install -r requirements.txt
uvicorn server:app --reload

# Frontend
cd frontend
yarn install
yarn start
```

The app should now be running at `http://localhost:3000` (frontend) with the API on `http://localhost:8000`.
